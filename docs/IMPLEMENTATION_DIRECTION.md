# SafeHour 구현 방향

작성일: 2026-07-30

## 한 문장 목표

SafeHour는 일반 관광 추천 앱이 아니라, 성형외과·피부과 수술·시술 후 외국인 환자와
동반 보호자가 병원의 주의조건과 복귀시간을 어기지 않도록 관광 선택지를 제한하고,
현장 변화가 생기면 안전한 대안으로 코스를 다시 계산하는 서비스다.

## 구현 우선순위

### 1. 안전 판정이 가능한 데이터 파이프라인

`TourAPI 실데이터 → 다국어·무장애 정규화 → 병원 조건 판정 → 복귀 SLA → 추천`

이 흐름을 서비스의 중심축으로 둔다. 화면을 먼저 늘리기보다, 모든 추천에 “왜 가능하고
왜 제외됐는지”를 설명할 수 있는 판정 근거를 남긴다.

### 2. 과제 1의 차별점인 변화 대응

휴무, 기상 악화, 교통 급증, 진료시간 변경, 환자 호출을 단순 알림으로 끝내지 않는다.
이벤트가 발생하면 기존 후보를 다시 판정하고 다음 중 하나를 사용자에게 보여준다.

- 유지: 조건과 복귀 SLA를 계속 충족
- 축소: 체류시간을 줄여 복귀 가능
- 대체: 부적합 장소를 제거하고 다음 안전 후보를 제시
- 취소·복귀: 관광을 중단하고 병원 또는 숙소 복귀

### 3. 환자와 보호자를 분리해 설계

- 환자: 병원 조건과 보수적 이동 버퍼를 적용한 초단거리·저부담 코스
- 보호자: 환자 휴식 중 분리 허용 여부, 호출 시 복귀 SLA를 적용한 근거리 코스
- 필수 동행 조건이 있으면 보호자 단독 관광을 제안하지 않음

## 지금 완료된 범위

- 국문·영문·무장애 TourAPI 호출 및 호출량·오류 로그
- 영문 우선·국문 폴백 후보 정규화
- 영문 API의 별도 콘텐츠 유형 코드 정규화
- 무장애 신호의 제한적 보행부담 보정
- 현재 GPS 거부, 사용자 선택 고정 좌표와 20km 이내 반경만 허용
- 병원 조건, 최대 보행·이동시간, 복귀 SLA 판정
- 환자·보호자 상태 전환과 위험 시 관광 미추천
- 숙박시설 등 비관광 활동 후보 제외
- 상위 추천만 `detailCommon2`, `detailIntro2`, `detailImage2`로 보강
- 운영·휴무 원문은 보존하되 현재 영업 여부는 임의 해석하지 않음
- 이미지 다운로드 없이 URL과 저작권 구분코드만 보존
- 실데이터 상위 3개 추천 및 1순위 휴무 시 자동 대체
- 46개 자동 테스트

## 다음 개발 순서

### P0 · 심사 시연에 필요한 최소 제품

1. 회복조건 입력 화면
   - 의료진·코디네이터가 제공한 조건만 구조화
   - 앱이 증상이나 외출 가능 여부를 스스로 진단하지 않음
2. 환자·보호자 모드가 분리된 추천 결과 화면
   - 추천 3개, 제외 이유, 복귀 마감, 데이터 출처 표시
3. 변화 재계산 시연 화면
   - 변경 전후 코스와 제거·대체·축소 사유를 한 화면에서 비교

### P1 · 실제 이동과 환경 변수

1. 위치정보지원센터 사전검토 결과에 맞춘 지도·경로 API 연결
2. 지도 API 전에는 보수적 직선거리 폴백과 “예상치” 표시 유지
3. 기상청 단기예보 연동과 실외 후보 재판정
4. API 실패·번역 누락·운영시간 불명 상태의 사용자 안내

### P2 · 공모전 완성도

1. 다국어 UX와 국문 폴백 번역 검수 흐름
2. 병원·숙소별 테스트 좌표 시나리오 확대
3. 감사 로그와 TourAPI 활용 지표를 관리자 증빙 화면으로 시각화
4. 접근성, 모바일 반응형, 오류 복구, 성능 검증

## 절대 지켜야 할 경계

- 관광 가능 여부나 위험 증상을 의료적으로 진단하지 않는다.
- 병원이 입력한 조건이 없거나 오래됐거나 상충하면 관광을 추천하지 않는다.
- 현재 GPS를 서버로 전송하지 않는다.
- 확인되지 않은 장소 운영시간·실내 여부·접근성을 사실처럼 표시하지 않는다.
- API 원문과 SafeHour 자체 추정값을 같은 필드에 섞지 않는다.
- 관광지·의료기관 알선으로 해석될 수 있는 순위나 수수료 기반 추천을 두지 않는다.

## 완료 판단 기준

심사 시연에서 다음 장면이 끊김 없이 동작하면 P0가 완료된 것으로 본다.

1. 병원·숙소 기준점을 사용자가 선택한다.
2. 병원 주의조건과 복귀시간을 입력한다.
3. 환자 또는 보호자에게 근거가 있는 추천 3개가 보인다.
4. 1순위 장소 휴무 또는 날씨 악화 이벤트를 발생시킨다.
5. 해당 장소가 제거되고 대체·축소·복귀 결과와 이유가 즉시 표시된다.
