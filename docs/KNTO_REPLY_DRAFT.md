## 본문

안녕하세요, 대외개방운영팀 담당자님.

SafeHour 개발자입니다. 문의 주신 국문 관광정보 서비스_GW 활용 확인 건에 대해 안내드립니다.

**먼저 확인이 어려우셨던 이유를 말씀드립니다.**

SafeHour는 수술·시술 후 회복 중인 환자와 보호자가 병원이 정한 주의조건과 복귀시간을
지키는 범위에서만 관광 활동을 추천하는 서비스입니다. 서비스 특성상 병원이 발행한
회복 지침을 연결한 뒤에 추천이 이루어지는 구조라, 첫 화면에서는 관광정보가 노출되지
않습니다. 확인에 불편을 드려 죄송합니다.

담당자님께서 계정 없이 바로 확인하실 수 있도록 **체험 경로를 열어두었습니다.**

### 확인 경로 (로그인 불필요, 약 1분)

1. https://safehour.vercel.app/login 접속
2. **「로그인 없이 둘러보기 (데모)」** 클릭
3. **「예시 A — 외출 가능」** 클릭 → 병원 지침 연결
4. **「오늘의 회복 상태 보기」** → **「병원 안내 확인하기」** → **「전체 확인 처리」**
5. **「안전 외출 확인」** → **「안전 판정으로 추천 받기」**

5번 화면에 **국문 관광정보 서비스_GW로 조회한 관광지 목록**이 표시됩니다.
(예: 스타필드 코엑스몰, 파르나스몰, 한국종합무역센터(코엑스) — 기준점 반경 3km 조회 결과이며,
조건에 맞지 않는 장소는 「제외된 장소와 이유」 에서 사유와 함께 확인하실 수 있습니다.)

각 카드의 **「추천 근거와 원문 보기」** 를 누르시면 장소 상세로 이동하며,
개요 원문 바로 아래에 `출처: ⓒ한국관광공사` 를 표기하고 있습니다.
결과 화면 하단에도 `관광정보 출처: ⓒ한국관광공사` 를 상시 표기합니다.

※ 예시 지침은 비식별 데모 데이터이며 실제 환자·병원 정보가 아닙니다.

### 국문 관광정보 서비스_GW 활용 내역

| 오퍼레이션 | 사용 시점 | 화면에서 확인되는 결과 |
| --- | --- | --- |
| `locationBasedList2` | 추천 생성 시 기준점 반경 3km 조회 | 추천 관광지 목록 (제목·거리) |
| `detailIntro2` | 추천 후보 상위 5건의 운영·휴무 확인 | 휴무일·행사 종료 장소를 추천에서 제외 |
