## 1. 무엇을 봐주셔야 하나

SafeHour는 성형외과·피부과 시술을 받은 **외국인 환자**에게, 병원이 정한 조건과 복귀시간
안에서만 외출 선택지를 보여주는 서비스입니다.

화면은 한국어·영어를 지원하고, **영어 사용자에게는 영문이 유일한 안전 지시입니다.**

봐주실 것은 **문체가 아니라 의미**입니다.

> **영문을 읽은 외국인 환자가, 한국어를 읽은 사람과 다르게 행동하게 되는 지점**

문장이 어색하거나 더 자연스러운 표현이 있어도, **의미가 같으면 통과**로 봐주세요.
저희가 찾는 것은 그것이 아닙니다.

### 특히 이런 것

| 유형 | 예 |
| --- | --- |
| **범위·배타성이 사라짐** | "…만 가능" → 영문에 "only"가 없음 |
| **금지가 허가로 약해짐** | "하지 마세요" → "할 수 있습니다" |
| **의무가 선택으로 약해짐** | "반드시 …해야" → "…하는 것이 좋습니다" |
| **행위 주체가 바뀜** | 누가 무엇을 해야 하는지가 달라짐 |
| **의료 판단처럼 들림** | 영문이 한국어보다 단정적이어서 진단처럼 읽힘 |
| **긴급도가 낮아짐** | 즉시 복귀가 권유처럼 들림 |

## 2. 직접 눌러보실 수 있습니다 (5분)

문맥을 보시면 판단이 훨씬 쉽습니다.

1. https://safehour.vercel.app 접속
2. 우측 상단 **English** 토글
3. 로그인 화면 → **"Explore without signing in (demo)"**
4. 연결 코드 화면에서 **Sample A** (정상) 또는 **Sample B** (외출 제한)

`Sample B`를 권합니다 — **아무것도 추천되지 않는 화면**의 문구가 이 검수에서 가장 중요합니다.

> 데모 계획은 비식별 예시입니다. 실제 병원 정보가 아닙니다.

## 3. 왜 이 검수가 중요한가

이 서비스에서 영문 문구는 **UI 라벨이 아니라 안전 지시**입니다.

예를 들어 판정 결과가 `SPLIT_NEARBY`일 때 한국어는 이렇게 나옵니다.

> **보호자만 근거리 활동이 가능합니다**

여기서 **"만"**이 핵심입니다 — 환자는 나가면 안 된다는 뜻입니다. 이 배타성이 영문에서
사라지면, 영어를 읽은 환자가 보호자를 따라 나갈 수 있습니다.

**시술 직후 환자에게는 그것이 실제 위험입니다.**

#### 🔴 위험 1건 — 이것만은 꼭

**[1] 판정 상태 `SPLIT_NEARBY` (배너 두 줄)**

| | |
| --- | --- |
| 한국어 | 보호자**만** 근거리 활동이 가능합니다<br>환자는 휴식, 보호자는 원터치 복귀 준비 |
| 현재 영문 | Companion **may** take a nearby activity<br>Patient rests, companion keeps one-tap return |

**문제** — 두 줄이 같은 방향으로 무너집니다. ① 배타 조사 **"만"**이 사라지고 `may`는
순수 허가라 환자 가부에 침묵합니다. ② **"환자는 휴식"**이라는 지시가 `Patient rests`라는
3인칭 서술이 되어 상태 묘사로 읽힙니다. **영문 배너에는 환자를 제약하는 표현이 한
군데도 남지 않습니다.**

**결과** — 시술 직후 환자가 "보호자가 나가도 된다니 나도"로 읽고 함께 나갑니다.
이 판정의 유일한 목적(환자 격리 휴식)이 영문에서만 무력화됩니다.

**참고** — 환자 탭을 열면 *"Rest comes first for the patient right now…"* 가 뜹니다.
완전 무방비는 아니고, **배너만 보고 화면을 닫는 경우**가 위험 구간입니다.

**대안(참고)** — `Only the companion may go out nearby.` /
`The patient must rest; the companion must stay ready to return in one tap.`

#### 🟡 주의 6건

**[2] `result.returnCta` — 다른 문구와 완전히 겹칩니다**

| | |
| --- | --- |
| 한국어 | 즉시 복귀 **안내** (버튼) |
| 현재 영문 | `Return now` |

같은 영문이 **복귀 시트 제목**(한국어 "지금 복귀하세요")에도 쓰입니다. 한국어는
**안내(버튼)**와 **지시(시트 제목)**를 구분하는데 영문은 글자까지 같습니다.

**결과** — 함께 외출 가능 판정을 받은 사용자가 복귀 생각이 없어 버튼을 안 눌러,
이상이 생기기 전에 복귀 절차를 미리 읽을 기회를 잃습니다. 반대로 명령으로 읽은
사용자는 방금 허가받은 활동을 취소합니다.

**대안(참고)** — 버튼을 `How to return now` 로 (시트 제목은 그대로)

**[3] `FASTING_REQUIRED` — 마시는 것이 빠졌습니다**

| 한국어 | 금식 중이라 **식음** 활동을 제외했습니다 |
| --- | --- |
| 현재 영문 | Fasting — **food** activities excluded |

**대안(참고)** — `Fasting — food and drink activities excluded`

**[4] `today.deadlineReturnBy` — 순환 설명이 됩니다**

| 한국어 | **병원** 복귀 시각 기준 |
| --- | --- |
| 현재 영문 | set by your return time |

'병원'이 빠졌습니다. 같은 줄의 마감 표시도 `Be back by {시각}`이라 복귀 대상을 말하지
않아, 영문에서는 **"복귀 시각은 복귀 시각 기준"**이라는 순환이 됩니다.
(다른 두 사유 — medication / next appointment — 는 대상이 분명합니다.)

**결과** — 마감을 '숙소로 돌아오는 시각'으로 읽고 숙소에서 대기합니다. 실제로는
**병원 복귀** 시각이라 처치를 놓칩니다.

**대안(참고)** — `set by your hospital return time`

판정: ☐ O   ☐ △   ☐ X · 대안 문구: ________________________________

**[5] `NO_TOURISM.action` — '대기'가 '휴식'이 됐습니다**

| 한국어 | 병원 연락 또는 숙소 **대기** |
| --- | --- |
| 현재 영문 | Contact hospital or **rest** at accommodation |

'대기'는 **다음 확인까지 그 자리에 머무르라**는 지시인데 `rest`는 활동의 종류(휴식)입니다.
이동 금지와 재확인 대기가 사라졌습니다. 가장 보수적인 판정의 유일한 행동 지시입니다.

**결과** — 숙소에서 쉬다가 컨디션이 나아졌다고 느끼면 **재확인 없이** 외출합니다.

**대안(참고)** — `Contact the hospital, or stay at your accommodation and wait.`

판정: ☐ O   ☐ △   ☐ X · 대안 문구: ________________________________

**[6] `RISK_SIGNAL` — 'condition'이 두 뜻으로 겹칩니다**

| 한국어 | 주의가 필요한 **상태**가 입력되었습니다 |
| --- | --- |
| 현재 영문 | A **condition** requiring attention was reported |

바로 앞 세 항목이 `Hospital conditions not provided / outdated / conflict`입니다.
한국어는 병원 **주의조건**과 환자 **상태**를 다른 단어로 구분하는데, 영문은 한 단어로
뭉개졌습니다. 목록에 나란히 보이는 자리라 충돌이 드러납니다.

**결과** — 자기 증상 때문에 막힌 줄 모르고 **입력 오류로 오해**합니다.
병원에 연락하는 대신 앱 입력만 다시 손봅니다.

**대안(참고)** — `A symptom requiring attention was reported`

판정: ☐ O   ☐ △   ☐ X · 대안 문구: ________________________________

**[7] `UV_EXPOSURE` — 무엇이 제외됐는지가 없습니다**

| 한국어 | 자외선 회피 조건으로 **실외 노출 장소를** 제외했습니다 |
| --- | --- |

조언으로 약해졌습니다. 같은 목록의 기상 사유는 대상을 밝히고 있어 형식도 어긋납니다.

**결과** — 병원 지침이 아닌 **상식 조언**으로 받아들여, 추천 목록 밖에서 햇볕 드는

## 5. 회신 방법

각 항목에 **O / △ / X** 와 필요하면 대안 문구를 적어주세요.

| 표시 | 뜻 |
| --- | --- |
| **O** | 의미가 같다. 그대로 두어도 된다 |
| **△** | 의미가 좁거나 넓다. 고치는 편이 낫다 |
| **X** | **다르게 행동할 수 있다. 반드시 고쳐야 한다** |

마지막에 아래를 적어주시면 그대로 심사 증빙으로 씁니다.

```

검수일: 2026-__-__

조건부인 경우 반드시 고쳐야 할 항목 번호: ______________________
```

## 6. 저희가 정말 모르는 것

확인 항목과 별개로, 답을 만들 수 없어 여쭙는 것입니다.

1. **긴급 문구의 톤** — 영어권 의료 맥락에서 "Return now"는 충분히 강한가요,
   아니면 "Return to the hospital immediately" 같은 형태여야 합니까?
2. **"Contact your hospital"** — 시술 후 환자에게 이 표현이 자연스럽습니까?
   `clinic`이 더 맞는 맥락입니까?
3. **의료 판단으로 읽힐 위험** — 영문 문구 중 "이 앱이 내 상태를 판단하고 있다"로
   읽히는 것이 있습니까? 저희는 의료 판단을 하지 않는다는 것이 제품의 전제입니다.
4. **119** — 영어 사용자가 이해할 수 있습니까? 부연이 필요합니까?
