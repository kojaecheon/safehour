# 결정 기록

되돌리기 어려운 결정만 남긴다. "같은 상황에서 다른 팀이 다르게 고를 수 있었나"에 그렇다고 답할 수
있어야 기록 대상이다. 각 기록은 맥락, 고른 것, 버린 대안과 버린 이유, 그 결정이 앞으로 막는 것을 담는다.

파일 이름은 네 자리 번호 + 짧은 이름이다. 새 기록은 가장 큰 번호 + 1로 만들고 이 목록에 한 줄 더한다.
`0000-template.md`가 뼈대다.

| 번호 | 주제 | 파일 |
| --- | --- | --- |
| 0001 | 화면 계약의 라우트 구조 | `0001-route-contract.md` |
| 0002 | 계측 범위와 동의 경계 | `0002-instrumentation-scope.md` |
| 0003 | 다국어 전략과 언어 결정 경로 (0007이 개정) | `0003-language-strategy.md` |

0003은 "언어를 서버로 보내지 않는다"고 정했고, 0007이 관광 데이터 언어를 고르기 위해 이를 개정했다.
지금 유효한 규칙은 0007이다 — 언어는 서버로 보내되 판정 결과는 언어와 무관해야 한다.
