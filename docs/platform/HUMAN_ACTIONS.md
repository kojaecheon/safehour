## 키가 없어서 꺼져 있는 기능

| 기능 | 필요한 것 | 꺼져 있을 때 |
| --- | --- | --- |
| 실제 주소 검색 | `JUSO_API_KEY`(검색), `JUSO_COORD_API_KEY`(좌표) | 503 `SAFEHOUR_ADDRESS_UNAVAILABLE`. 데모 로그인 모드에서는 데모 주소 |
| AI 일정 소개 문장 | `SAFEHOUR_AI_INTRO=1`과 `GEMINI_API_KEY`(둘 다), 사용 승인 | 템플릿 문장 |
| 일본어·중국어 관광 데이터 | 관광공사 일본어·중국어(간체) 서비스 활용 신청 | 영문 대체 → 국문 + '번역 필요' |

- 일본어·중국어 안전 문구 검수 스위치는 `NEXT_PUBLIC_SAFEHOUR_SAFETY_COPY_REVIEWED_JA`,
  `NEXT_PUBLIC_SAFEHOUR_SAFETY_COPY_REVIEWED_ZH`다. 값이 `1`일 때만 켜지고, 빌드 시점에 읽으므로 바꾸려면 다시 빌드해야 한다.
- AI 모델은 `GEMINI_MODEL`로 바꿀 수 있다.
- 관광공사 호출 한도 환경변수는 `TOUR_API_WARNING_AT`(경고, 기본 800)과 `TOUR_API_DAILY_LIMIT`(차단, 기본 1,000)이다
  (`src/tour-api/config.js`). 설명은 `.env.example`에 있다.
