# 규칙

어기면 빌드·테스트·실행이 깨지거나 구조가 어긋나는 것만 적는다. 취향은 규칙이 아니다.

## 의존성

- **패키지를 추가·변경·삭제하지 않는다.** `package.json`의 dependencies·devDependencies와
  `package-lock.json`은 건드리지 않는다. 설치는 `npm ci`(잠금 파일 그대로)만 쓴다.
  - 위반 판정: `git diff`에 두 파일이 나타난다.
  - 새 기능에 라이브러리가 필요해 보이면 표준 기능으로 만든다. 좌표 변환, PIN 암호화, 압축,
    외부 API 호출이 모두 이 방식으로 들어와 있다 — 선례를 따르면 된다.
  - 정말 필요하면 구현하지 말고 운영자에게 묻는다.
- `npx`로 새 도구를 내려받아 실행하지 않는다.
- `package.json`의 `overrides`는 취약점 대응으로 들어간 고정값이다. 임의로 풀지 않는다.

## 검증 관문

| 변경 종류 | 통과해야 하는 것 |
| --- | --- |
| 일반 코드 | `npm run lint`, `npm test` |
| 화면·라우팅·빌드 설정 | 위 + `npm run build` |
| 엔진·안전 게이트·복귀 계산·사건 | 관련 단위 테스트 + 전체 `npm test` |
| 화면 흐름 | 위 + `npm run e2e` |
| 외부 API 연동 | 가짜 응답 테스트 먼저. 실제 호출 증적은 키가 있는 환경에서 수동으로만 |

`npm run check`(lint → test → build → audit)가 기준선이다. 실제 외부 API를 부르는 명령은 호출량과
증적을 만들기 때문에 자동 검증에 넣지 않는다.

**코드를 고치기 전에 실패·경계·완료 조건을 테스트 문장으로 먼저 고정한다.** 안전 판정이 걸린 규칙은
테스트가 없으면 조용히 느슨해진다.

## 테스트

- 단위 테스트는 `node --test`로 `test/*.test.js`를 돈다. **외부 호출이 없어야 한다** — 가짜 데이터만 쓴다.
- 화면 테스트는 360px 기준이고 **외부 호출 0건**이어야 한다. 캐시 씨앗 스크립트가 관광공사 응답을
  미리 심고, 네트워크 감시가 외부 요청을 실패로 만든다.
- 새 화면은 접근성 검사 위반 0건, 키보드 조작 가능, 200% 확대에서 깨지지 않음, 터치 대상 44px 이상을
  만족해야 한다.
- 테스트 데이터에 API 키, 전체 조회 URL, 병원 안내문 원문, 실제 이름·연락처를 넣지 않는다.
- 기존 테스트가 새 결정과 충돌하면 **의도적으로** 고치고 고친 이유를 커밋 메시지에 남긴다.
  조용히 지우거나 건너뛰지 않는다.

## 모듈 경계

의존은 한 방향이다.

```
src/domain → src/stay → src/engine → lib/server → app
                ↑            ↑           ↑
          src/tour-api  src/adapters  src/auth · src/recovery · src/guardian · src/i18n
                                          ↑
                              lib/store → lib/trip → components
```

- `src/` 아래 순수 규칙·엔진 모듈은 **브라우저 API를 참조하지 않는다.** `window`·`document`·
  `localStorage`를 쓰는 순간 `node --test`에서 불러올 수 없게 된다.
- 순수 규칙 모듈은 네트워크를 직접 부르지 않는다. 외부 호출은 어댑터가 하고 결과를 인자로 받는다.
- 화면(`app/`, `components/`)은 엔진을 직접 부르지 않는다. 라우트 핸들러를 통해 부른다.
- 클라이언트 코드는 서버 전용 모듈(`lib/server/`, `src/auth/`)을 불러오지 않는다.

## 값이 사는 곳

| 값의 종류 | 정본 위치 | 규칙 |
| --- | --- | --- |
| 조정 가능한 숫자 기본값 | `src/stay/defaults.js` 한 파일 | 다른 모듈은 **읽기만** 한다. 새 값이 필요하면 추가하지 말고 보고한다 |
| 단서 목록(열·물·매운·날음식·주점·카페, 관심사 매핑) | 관광 후보 모듈의 상수 한곳 | 화면·엔진에 복제하지 않는다 |
| 날짜 상태와 사유 코드 | `src/domain/states.js` | 닫힌 집합이다. 새 사유가 필요하면 추가 전에 보고한다 |
| 화면 문구 | `src/i18n/messages/<기능>.js` | 기능별 이름공간 파일에만 쓴다. 등록 파일은 따로 관리한다 |
| 스타일 토큰 | `app/globals.css` | 기능별 스타일 파일은 토큰만 쓴다. 색·크기 값을 직접 쓰지 않는다 |

**'사람 검토 전 임시값' 표시가 붙은 기본값을 더 느슨하게 바꾸지 않는다.** 의료진 검토를 거쳐야
확정되는 값이고, 느슨하게 바꾸면 안전 판정이 조용히 완화된다.

## 안전 규칙의 구조적 강제

도메인 규칙 자체가 아니라, 그 규칙을 코드 구조로 지키는 방법이다.

- **허용 목록은 양쪽에 둔다.** 클라이언트가 요청을 깎고, 서버가 다시 깎는다. 한쪽만 있으면 다른 쪽
  실수가 그대로 나간다. 허용 목록 밖 필드를 버리는 테스트를 각 경계마다 둔다.
- **운영 로그는 조립 함수만 필드를 만든다.** 호출자가 넘긴 객체를 펼쳐 쓰지 않는다. 펼치면 엔진이
  필드를 추가할 때마다 로그가 따라 커진다.
- **판정 계층은 현재 시각·난수·현재 위치를 직접 읽지 않는다.** 현재 시각은 인자로 받는다.
  시계를 읽는 곳은 라우트 계층 한 곳뿐이고, 값은 서버 시계에서 온다. 요청 본문에 실려 온 시각은
  쓰지 않는다 — 클라이언트가 '오늘'을 옮겨 매일 확인 게이트를 우회할 수 있다.
- **판정 경로는 하나다.** 같은 판정을 하는 두 번째 함수·라우트·화면을 만들지 않는다. 두 벌이 되면
  결과가 어긋나고, 그게 이 제품에서 가장 위험한 결함이다.
- **안전 판정에 관한 규칙은 테스트가 있어야 한다.** 규칙을 바꾸면 테스트도 같은 커밋에서 바꾼다.

## 작업 단위와 기록

- 한 작업은 1–2일 크기를 넘기지 않는다.
- 작업 ID는 `AX-` + 세 자리 숫자 형식이다. 브랜치는 `feature/`·`fix/`·`docs/` + 작업 ID + 짧은 이름.
- 커밋 메시지와 변경 설명은 **한국어**로 쓴다.
- 변경마다 남길 것: 작업 ID, 사용자 가치와 범위 밖 항목, 변경 파일과 중요한 결정, 실행한 검증
  명령과 결과, 남은 위험과 사람 승인 항목.
- 정책·API 계약·상태 의미가 바뀌면 코드만 고치지 말고 관련 문서와 테스트를 같은 변경에서 갱신한다.
- 되돌리기 어려운 결정은 `docs/decisions/`에 번호를 붙여 남긴다. 맥락, 고른 것, 버린 대안과 버린
  이유, 그 결정이 앞으로 막는 것을 적는다.
- 기본 브랜치는 `main`이다.

## 기존 파일

**기존 문서·설정을 통째로 덮어쓰지 않는다.** 필요한 부분만 고치고 변경 내용이 드러나게 한다.
공모전 제출 관련 문서(`docs/COMPETITION_SUBMISSION.md`, `docs/FUNCTION_SPEC_DRAFT.md`,
`docs/KNTO_REPLY_DRAFT.md`, `docs/REVIEW_EN_SAFETY_COPY.md`, `docs/SIGNOFF_CHECKLIST.md`,
`docs/API_USAGE_*`, `docs/notion/*`)는 제출 시점 상태 그대로 둔다 — 심사 대상 산출물이다.

## 환경 설정

- 서버 비밀값은 서버 코드에서만 읽는다. `NEXT_PUBLIC_` 접두사가 붙은 값은 **빌드 때 번들에 새겨지는
  공개 값**이므로 비밀값을 넣지 않는다.
- 스위치 환경변수는 **방향에 따라 다르게 읽는다.** 기능을 **켜는** 스위치(AI 소개, 데모 로그인)는
  값이 정확히 `1`일 때만 켜진다 — `true`·`on`·앞뒤 공백이 붙은 값은 꺼짐이다. 기능을 **끄는**
  안전 스위치(추천 중단)는 `1`·`true`·`on`을 모두 켜짐으로 읽는다(앞뒤 공백·대소문자 무시).
  급할 때 오타로 안 걸리는 쪽이 안전하기 때문이다. 새 스위치를 만들면 어느 쪽인지 먼저 정한다.
- 새 환경변수를 쓰면 `.env.example`에 이름·용도·기본 동작·없을 때 동작을 함께 적는다.

## 외부 API 형식

외부 API의 요청·응답 형식(서비스 유형 코드, 좌표 체계와 변환 매개변수, 모델 이름, 전화 발신 형식)을
**기억으로 쓰지 않는다.** 공식 문서나 저장소의 실응답 예시로 확인하고 근거를 주석이나 문서에 남긴다.
확인할 수 없으면 추정으로 구현하지 말고 보고한다.

## 멈추고 보고해야 하는 때

같은 오류를 두 번 시도해도 못 풀면 멈추고 보고한다. 위험한 추천, 위치 수집, 비밀값 노출, 의료 판단,
저작권 위반 가능성이 보이면 병합보다 보류를 우선한다.
