# SEED 디자인 시스템 적용 설계

- 작성일: 2026-09-24
- 브랜치: `claude/medical-tourism-platform-c60a55` (로컬 커밋만 — 병합·배포·push 없음)
- 참고: SEED Design (https://seed-design.io/, 당근). 값의 출처는 SEED 저장소 `daangn/seed-design` `dev` 브랜치의
  `packages/rootage/*.yaml`(토큰·부품 명세)과 `packages/css`(구현). 이 문서에 쓰는 SEED 값은 모두 그 출처에서 옮겼다.

## 1. 목적

기능은 모두 동작하지만 화면이 '도구'처럼 보인다. SEED의 레이아웃·부품·위계를 가져와 실제 서비스처럼 보이게 한다.
색은 지금 기조를 유지하고, 안전 표시 원칙은 한 글자도 느슨하게 하지 않는다.

## 2. 운영자가 정한 것 (2026-09-24 대화)

| 질문 | 결정 |
| --- | --- |
| 색을 어디까지 SEED로 | **회색 체계만** SEED로. 코발트 포인트·벚꽃 분홍·상태 4색·긴급 빨강·출처 색은 지금 값 유지 |
| 다크 모드 | **이번에는 라이트만.** 토큰은 '의미 이름 → 값' 구조라 나중에 다크 값만 더하면 된다 |
| 충실도 | **SEED 구조 + 우리 안전 하한.** SEED 값이 하한에 못 미치면 SEED 자기 척도 안의 다음 단계로 올린다 |
| 진행 방식 | **층별로 확인하며** — ① 토큰 → ② 부품 → ③ 화면(흐름 순서, 한 화면씩) |
| '선택됨' 표시 색 | **SEED대로 진한 회색.** 코발트는 화면당 주 버튼 하나·링크·타임라인 선·'오늘' 표시에만 쓴다 |

버린 안: SEED 값을 그대로 쓰기(안전 규칙 위반), 색 토큰 이름까지 SEED식으로 전부 바꾸기(모든 스타일 파일이 바뀌어 비용 대비 이득이 없음),
한 번에 전부 바꾸기(중간에 방향을 틀기 어려움), SEED 패키지 설치(의존성 동결 — `package.json`·`package-lock.json` 수정 금지).

## 3. 제약 (넘지 않는다)

- **새 패키지 설치 금지.** `@seed-design/*`를 쓰지 않는다. SEED 규칙을 우리 CSS와 부품으로 다시 구현한다.
- **글꼴은 시스템 글꼴만.** 빌드·실행 중 내려받지 않는다(SEED도 시스템 글꼴이 기본이다).
- **토큰 정본은 `app/globals.css` `:root` 한 곳.** 기능별 스타일은 `var(--…)`만 쓴다.
- **문구는 문구 사전(`src/i18n/messages/`)에서.** 4개 언어가 모두 있어야 한다.
- **안전 표시 원칙 유지**: 본문 16px 이상, 터치 대상 44px 이상, 상태를 색만으로 구분하지 않음, `NO_TOURISM`을 오류 스타일로 그리지 않음,
  WCAG 2.1 AA 대비(글자 4.5:1, 큰 글자·UI 경계 3:1), 출처 영역을 시각적으로 나눔, 배지 5종의 뜻 유지, '안전합니다' 금지.
- 판정·저장·API는 건드리지 않는다. 이 작업은 표시만 바꾼다.

## 4. ① 토큰 설계

원칙: **지금 토큰 이름은 그대로 두고 값만 바꾼다. 없는 개념만 새 토큰으로 더한다.** 그래서 이 층을 적용해도 화면이 깨지지 않고
앱 전체가 SEED 쪽으로 한 번에 옮겨 간다. 부품과 화면의 구조 변경은 ②·③층에서 한다.

### 4.2 글자

SEED 단계를 쓴다. 줄 높이는 비율이 아니라 **px 고정 짝**이다.

| 토큰 | 지금 | 새 값 | SEED |
| --- | --- | --- | --- |
| `--text-display` | 30px | **26px / 35px** | t10 · screenTitle |
| `--text-title-1` | 24px | 24px / 32px | t9 |
| `--text-title-2` | 20px | 20px / 27px | t7 |
| `--text-title-3` | 18px | 18px / 24px | t6 (상단 바 제목) |
| `--text-body` | 16px | 16px / 22px (UI) · 16px / 24px (긴 글) | t5 · articleBody |
| `--text-button` | 17px | **16px / 22px** (큰 CTA는 18px / 24px) | SEED medium은 14px — 하한 16px로 올림 |
| `--text-caption` | 14px | 14px / 19px | t4 |
| `--text-korean-card` | 30px | 30px 유지 | 예외 — 멀리서 보여 주는 카드 |

- **줄 높이**: 기존 비율 토큰은 어떤 글자 크기에도 쓰이므로 px로 바꾸지 않는다(바꾸면 30px 한국어 카드의 줄 높이가 22px로 줄어든다).
  비율만 SEED 짝에 맞춘다 — `--leading-tight` 1.25 → **1.33**(24/32), `--leading-snug` 1.4 → **1.375**(16/22), `--leading-body` 1.6 → **1.5**(16/24).
  px 짝이 필요한 부품(버튼·입력·목록 행)을 위해 새 토큰을 더한다:
  `--lh-display: 35px`, `--lh-title-1: 32px`, `--lh-title-2: 27px`, `--lh-title-3: 24px`, `--lh-body: 22px`, `--lh-article: 24px`, `--lh-caption: 19px`.
- `--tracking-tight`(-0.02em) → `normal`. SEED에는 자간 토큰이 없다.
- `--weight-heavy`(800) → **700**. SEED 굵기는 400·500·700뿐이다.
- 글꼴 목록은 지금 것 유지(`:lang()`별 목록이 한·일·중 자형 섞임을 막는다). SEED 목록과 앞부분이 같다.

### 4.4 모서리

기존 모서리 토큰은 한 이름이 여러 부품에 섞여 쓰인다(`--radius-sm` = 입력·칩·작은 버튼). 값만 바꾸면 입력칸이 8px가 되는 식으로
틀어지므로, **①층에서는 SEED 단계 토큰을 새로 더하기만 한다.** ②층에서 부품마다 새 토큰으로 옮기고, 다 옮긴 뒤 안 쓰는 기존 토큰
(`--radius-xs`·`--radius-sm`·`--radius`·`--radius-lg`·`--radius-pill`)을 지운다.

| 새 토큰 | 값 | SEED | 쓰는 곳 (②층 이후) |
| --- | --- | --- | --- |
| `--radius-6` | 6px | r1_5 | 배지 |
| `--radius-8` | 8px | r2 | 작은 버튼(44px), 스낵바, 상단 바 아이콘 버튼, 그림 틀 |
| `--radius-10` | 10px | r2_5 | 안내 상자(Callout), 목록 행 눌림 |
| `--radius-12` | 12px | r3 | 큰 버튼, 입력칸, Select Box, 날짜 칩 |
| `--radius-16` | 16px | r4 | 누르는 카드(장소 카드), 뼈대 |
| `--radius-20` | 20px | r5 | 대화상자 |
| `--radius-24` | 24px | r6 | 시트 위 모서리 |
| `--radius-full` | 9999px | full | 칩, 스위치, Segmented Control |

규칙: 안쪽 모서리 = 바깥 모서리 − 바깥 안쪽 여백.

### 4.5 그림자·층

- `--shadow-card` → `none`. 카드는 그림자 대신 바탕 층으로 구분한다.
- `--shadow-float` → `0 4px 16px 0 rgba(0,0,0,0.122)` (SEED s3). 떠 있는 메뉴에만.
- `--shadow-sheet` → `none`. 하단 내비·하단 바는 그림자 대신 1px 윗선(`--line-strong`).
- 구역 구분은 **회색 바탕 위 흰 블록 + 8px 틈**. 8px짜리 회색 구분선 요소를 만들지 않는다.

### 4.6 눌림·초점·움직임

- **눌림**: 면 색만 바꾼다(`-pressed` 토큰). 글자·아이콘 색은 바꾸지 않는다. 반투명 덧칠을 쓰지 않는다.
  색 자체가 상태인 요소(스위치 켬/끔, 선택된 탭)는 눌러도 색을 바꾸지 않는다.
- **축소**: 눌리면 2px만큼 줄어든다 — `scale = (basis − 2) / basis`, `basis = max(높이, 너비/4, 24px)`. 150ms `cubic-bezier(0,0,.15,1)`.
  버튼·칩·탭은 요소 전체가, 목록 행은 내용만 줄어든다. 목록 행은 눌린 바탕이 좌우 6px 안으로 들어오고 모서리 10px.
  로딩·비활성·인라인 글자 링크는 줄지 않는다. `prefers-reduced-motion: reduce`면 줄지 않는다.
- **마우스 호버**: 눌림과 같은 색. `@media (hover:hover) and (pointer:fine)`에서만.
- **초점**: 2px 윤곽선, 바깥 2px 띄움(상단 바 아이콘 버튼은 안쪽 −2px). **색은 코발트** — SEED의 `#5e98fe`는 2.9:1이라 하한 미달.
  포인트 면·짙은 면 위에서는 `--ink` 윤곽선.
- **색 전환**: 150ms `cubic-bezier(.35,0,.35,1)`. 기존 `--duration-fast`(120ms)는 150ms로.

| 버튼 높이 | small 36 · medium 40 | **최소 44px** | 터치 44px |
| 칩 높이 | 32 · 36 · 40 | **최소 44px** | 터치 44px |

## 5. ② 부품 설계

부품 이름과 쓰는 법(props)은 되도록 유지하고 모양만 SEED로 바꾼다. 바꿔야 하는 경우만 새 변형을 더한다.

### 5.1 버튼 — `Button` (SEED Action Button)

| 변형 | SEED | 모양 |
| --- | --- | --- |
| `primary` | brandSolid | 코발트 채움 · 흰 글자 · 누르면 `--accent-strong` |
| `secondary` | **neutralWeak** | `#f3f4f5` 채움 · `--ink` 글자 · 누르면 `#eeeff1` (지금의 흰 바탕+테두리를 대체) |
| `quiet` | ghost | 투명 · 누르면 `--pressed-transparent`. 문장 속 글자 링크는 밑줄 유지 |
| 새 `critical` | criticalSolid | 되돌릴 수 없는 확인(동의 철회·삭제). 긴급 빨강 채움 |

| 크기 | 높이 | 모서리 | 좌우 여백 | 글자 | 아이콘 |
| --- | --- | --- | --- | --- | --- |
| `normal` (큰 CTA) | 52px | 12px | 20px | 18/24 · 700 | 22px |
| `small` | 44px | 8px | 16px | 16/22 · 700 | 16px |

- 규칙: 채운 강조 버튼(primary·critical)은 **화면당 하나**. 버튼을 셋 이상 나란히 두지 않는다. 채운 버튼 옆에 테두리 버튼을 두지 않는다.
  닫기·이전 같은 보조 버튼(neutralWeak)과 주 버튼을 나란히 둘 때 폭 3:7.
- 로딩 중에는 눌린 색 + 가운데 회전 표시(18px, 선 2px).
- 비활성: `--surface-alt` 바탕 + `--ink-subtle`(`#868b94`, 회색 바탕 위 3.1:1) 글자 + `cursor: not-allowed`. 투명도로 흐리게 하지 않는다.
  SEED `fg.disabled`(`#d1d3d8`)는 1.3:1이라 무엇이 적혀 있는지 읽히지 않아 쓰지 않는다(WCAG는 비활성 요소를 대비 기준에서 빼지만,
  왜 못 누르는지 읽혀야 한다). 못 누르는 이유는 지금처럼 버튼 옆 글자로 알린다.

`EmergencyButton`: 긴급 빨강 채움, 큰 CTA 모양(52px·모서리 12). 하단 내비 칸일 때는 5.8의 내비 규칙을 따른다.

### 5.2 입력 — Text Input · Field

- 입력칸(글자·날짜·시각): 높이 52px, 모서리 12px, 좌우 16px, 16/22, 테두리 1px `--line-input`.
  초점 때 **2px `--line-contrast`**, 오류 때 **2px 긴급 빨강**, 비활성·읽기 전용은 `--surface-alt`.
- 라벨: 16/22 · 700 · `--ink`, 마침표 없음. 입력칸과 8px 간격.
- 도움말: 14/19 · `--ink-soft`, 16px 아이콘. 오류는 같은 자리에 14/19 긴급 빨강 + 아이콘, `aria-live`로 알린다.

- 칸 5개 유지(오늘·일정·조건·더보기·긴급). 최대 폭 480px, **1px 윗선**(`--line-strong`), 그림자 없음.

### 5.9 아이콘 — `Icon`

- SEED 아이콘은 패키지라 쓰지 않는다. 지금 아이콘을 SEED 규칙에 맞춘다: 24px 격자, 기본 크기 24px(최소 12px),

- 새로 그리는 것: 하단 내비 5개의 **채운 모양**(선택 상태용). 나머지는 크기·선 굵기만 맞춘다.
