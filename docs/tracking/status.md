## 만들어졌고 테스트가 있는 것

**도메인·엔진**

- 체류 저장 규칙(날짜 역순·45박·수술 일정 필수·숙소 겹침), 입국일 시작·출국일 마감 창
- 조건 기간 저장·검증, 세 종류 답(값 있음/아니오/모르겠음), 항목별 엄격 합성과 출처 기록
- 날짜 분류 5종과 입력 필요 사유 4종, 수술 후 경계일 규칙
- 하루 일정 생성: 고정 블록, 외출 조립, 복귀 계산식, 보행 누적, 이동 한도, 식사 칸, 마감 이유 5종
- 병원 일정 직전 외출의 병원 복귀와 앞선 외출의 숙소 복귀, 예상 귀가 시각
- 보호자 단독 외출 네 조건
- 체류 전체 조립, 변화 감지, 최소 변경 재계획, 자동 대체, 전후 비교, 교체 후보(최대 5개)
- 오늘 게이트 덧씌우기, 즉시 복귀, 데모 사건 6종

**데이터·외부 연동**

- 관광공사 4개 언어 + 무장애 조회, 언어 매칭, 날짜 기준 휴무 판정, 식이·열·물 단서 분류
- 응답 캐시(15분)와 호출 한도, 캐시 본문의 기준점 좌표 제거
- 기상청 단기예보, 도로명주소 검색과 UTM-K→위경도 변환, 택시·대중교통·공항 이동 추정
- 병원 지침 계약 v2 게이트웨이(허용 목록), 데모 코드 3종

**서버**

- 일정·교체 후보·소개 문장·주소 검색·장소 상세·지침 연결·세션·상태 확인 경로
- 로그인 가드, 판정 운영 로그(개인정보 부재를 테스트로 고정), 추천 중단 스위치

**클라이언트·화면**

- 시작, 로그인, 체류 설정, 조건 입력·동의, 병원 연결, 병원 안내, 오늘, 전체 일정, 하루 일정,
  장소 상세, 한국어 카드, 긴급 연락, 더보기, 설정, 개인정보 고지, 보호자 링크 만들기·열기, 시안 보드
- 기기 저장소와 계정 이름공간, 보기 전용 모드, 출국 7일 후 삭제, 내 정보 지우기
- 보호자 스냅샷 최소화·PIN 암호화·잠금·만료
- 4개 언어와 안전 문구 병기, 홈 화면 설치와 보기 전용 오프라인, 기기 알림
- AI 소개 문장(기본 꺼짐)과 평가 도구

## 남은 것

우선순위 순. 지금 구현이 이쪽을 막지 않도록 저장 모델에 스키마 버전을 두고, 서버 라우트를 무상태로
두고, 지침을 어댑터로 받게 해 두었다.

1. **사람 승인 대기 항목 반영** — 의료진이 확정한 '모르겠음' 기본값·식이 목록·버퍼, 법무 검토를 마친
   동의 문구, 검수를 마친 일본어·중국어 안전 문구, 확인된 관광 안내 전화 발신 형식
2. **서버 저장과 동기화** — 계정별 서버 저장, 기기 간 동기화, 서버 푸시 알림
3. **보호자 실시간** — 보호자 실시간 동기화, 환자→보호자 호출, 보호자 2명 이상
4. **실제 병원 연동** — 병원 전용 어댑터와 표준 의료 데이터 매핑, 병원 발행 콘솔, 병원 측 감사 기록,
   지침 서명·위조 검증, 병원 안내문 다국어 원문 발행
5. **위치정보 검토 후 기능** — 경로 API, 지도 내장 화면, 숙소 출발 경로
6. **데이터 확장** — 관광공사 외 장소 데이터, 숙소 이동일의 체크아웃·체크인 시각 처리
7. **플랫폼 확장** — 추가 로그인 수단, 언어 추가와 번역 검수 체계, 네이티브 앱
8. **사업 모델** — 도입한다면 중립 추천·광고 표시 원칙을 먼저 정한 뒤에 한다

## 진행을 막는 것

- **운영 반영 금지 (2026-11-05까지).** 현재 배포 주소로 공모전 심사가 진행 중이다. 최종 심사 이후
  시상(2026-11-05)이 끝날 때까지 `main` 병합, 운영 배포, 원격 push, 새 검토 요청을 만들지 않는다.
  그 뒤 운영자가 병합·배포 시점을 정한다.
- **의존성 권고 3건이 남아 있다.** 잠금 파일을 바꿀 수 없어 해결하지 못했다.
- **실제 환자 대상 운영 불가.** 의료·법무·위치정보·번역 검수가 모두 사람 승인 대기다. 승인 전에는
  시연과 검증 용도로만 쓴다.
- **연동 병원 0곳.** 병원 연동은 데모 코드로만 동작한다.
