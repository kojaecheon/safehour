# 서버 측 조립 (`lib/server/`)

## 맡는 것

라우트 핸들러가 쓰는 서버 전용 부품이다.

- 로그인 가드
- 요청 본문 검증과 **허용 목록 적용**
- 일정 요청을 엔진 입력으로 바꾸고 응답을 만드는 조립
- 공항↔숙소 이동 추정(전용 상수)
- AI 소개 문장 호출과 출력 자동 검사, 템플릿 대체
- 판정 운영 로그
- 운영 스위치 상태

## 맡지 않는 것

- 판정 자체 — `src/engine/`
- 조건 합성·날짜 분류 — `src/stay/`
- 저장. 이 계층은 **아무것도 저장하지 않는다**. 예외는 서버 알림(`lib/server/watch/`, ADR-0012) 하나다. 그 폴더는 ADR-0012의
  네 레코드만 저장하고, 그것도 스위치(`SAFEHOUR_SERVER_PUSH`)가 켜졌을 때만이다. 규칙은 `lib/server/watch/AGENTS.md`
- 클라이언트 상태. 이 폴더는 브라우저에서 불러오지 않는다

## 항상 지켜야 하는 것

- **상태를 만들지 않는다.** 요청 사이에 남는 변수·파일·데이터베이스를 만들지 않는다. 조건 값은
  계산이 끝나면 버린다. 서버 알림(`lib/server/watch/`)만 예외로 Upstash Redis에 네 레코드를 두며, 조건 값은 거기에도 담지 않는다.
- 요청 본문의 허용 목록 밖 필드는 **조용히 버린다.** 오류로 만들지 않는다 — 클라이언트 실수를
  서버가 지워주는 것이 목적이다.
- **시계를 읽는 곳은 이 계층 하나다.** 엔진은 현재 시각을 인자로 받고, 그 값을 여기서 채운다.
  요청 본문에 실려 온 시각은 쓰지 않는다 — 클라이언트가 '오늘'을 옮겨 매일 확인 게이트와 지난 날짜
  보호를 우회할 수 있다. 시계는 주입할 수 있게 두어 테스트가 시각을 고정한다.
- **운영 로그는 조립 함수가 만든 필드만 내보낸다.** 호출자가 넘긴 객체를 펼쳐 쓰지 않는다.
  펼치면 엔진이 필드를 더할 때마다 로그가 따라 커진다. 좌표·날짜·장소 이름·주소·조건 값·계정 키·
  병원 정보는 어떤 경로로도 들어가지 않는다.
- 오류 응답의 식별자 키는 항상 `errorCode`다. 다른 이름을 쓰지 않는다.
- 외부 API 키는 헤더로 보낸다. 질의 문자열에 넣지 않는다 — URL은 중간 기록에 남는다.
- AI 호출은 **스위치와 키가 둘 다** 있을 때만 한다. 실패·시간 초과·검사 불합격이면 템플릿으로 바꾼다.
  AI 요청에 조건·병원·숙소·날짜 필드를 넣지 않는다.
- 상태 확인 경로는 키의 **존재 여부만** 알린다. 키 값을 담지 않는다.
- 추천 중단 스위치가 켜지면 판정 없이 모든 날짜를 정거장 0개로 돌려준다. 긴급·카드 경로는 막지 않는다.

## 구현 방식

- 로그인 가드는 핸들러를 감싸는 형태다. 새 경로를 만들면 감싸는 것을 잊지 않는다 — 감싸지 않으면
  로그인 없이 열린다.
- 공항 이동은 도심 추정기가 아니라 전용 상수를 쓴다(우회 계수·속도·터미널 이동). 도심 상수를 그대로
  쓰면 공항 구간이 네 시간으로 나온다. 이 값은 일반 이동 버퍼와 더하지 않는다.
- AI 출력 검사는 길이·문자 체계·금지 표현을 본다. 하나라도 걸리면 템플릿이다.

## 테스트

- 로그인 없이 각 경로를 불러 401과 정해진 오류 코드가 나오는지 확인한다.
- 허용 목록 밖 필드(숙소 이름·주소, 병원 이름·전화, 연결 코드)를 섞은 요청을 넣고 결과·로그·외부
  요청 어디에도 그 값이 없는지 단언한다.
- 민감한 값을 가득 채운 요청으로 로그 한 줄을 만들고, 금지 항목이 하나도 없는지 단언한다.
- AI는 세 경우를 고정한다: 스위치 꺼짐 → 템플릿, 금지 표현이 든 출력 → 템플릿, 요청 본문에 조건·
  병원 필드가 있어도 외부로 나가지 않음.
- 추천 중단 스위치를 켠 상태의 응답을 확인한다.
