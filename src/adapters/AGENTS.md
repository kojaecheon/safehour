# 외부 어댑터 (`src/adapters/`)

## 맡는 것

바깥 세계의 값을 이 제품이 쓰는 모양으로 바꾸는 얇은 층이다.

- 이동시간 추정: 도심 택시(제한일), 대중교통(자유일), 짧은 거리 도보
- 기상청 단기예보 조회와 '실외 적합' 판단 재료
- 행정안전부 도로명주소 검색
- UTM-K(GRS80) → 위경도 변환 — 라이브러리 없이 직접 계산한다
- 데모 로그인 모드에서 쓰는 고정 데모 주소

## 맡지 않는 것

- 추정값을 판정에 쓰는 일 — `src/engine/`이 받아서 쓴다
- 공항↔숙소 이동 추정. 그건 서버 쪽 공항 모듈이 전용 상수로 계산한다. 도심 추정기를 공항 구간에
  쓰지 않는다
- 캐시와 호출 한도 — 관광 데이터 쪽 모듈이 갖는다

## 항상 지켜야 하는 것

- **모든 이동시간은 추정이다.** 추정임을 표시할 수 있게 값과 함께 내보내고, 확정 시각처럼 다루지 않는다.
- 현재 위치를 쓰지 않는다. 출발지는 항상 사용자가 고른 고정 좌표다.
- 외부 호출이 실패하면 **판정을 막지 않는다.** 기상은 '확인 불가'가 되어 판정에 반영되지 않고,
  주소는 사용 불가 오류를 돌려준다. 실패를 "괜찮음"으로 바꾸지 않되 전체를 멈추지도 않는다.
- 외부 오류 원문·조회 URL·키를 그대로 던지거나 기록하지 않는다.
- 좌표 변환 결과는 대한민국 범위 안이어야 한다. 범위를 벗어나면 값을 쓰지 않는다.

## 구현 방식

- 추정기는 **함수를 만들어 돌려주는 모양**이다. 상수를 인자로 받아 다른 구성(공항 구간 등)을 만들 수
  있고, 테스트가 상수를 고정할 수 있다.
- 대중교통 추정은 직선거리 × 우회 계수 ÷ 속도 + 대기·환승 시간이다. 계수·속도·대기 시간은 체류
  도메인의 기본값 파일에서 읽는다.
- 기상 키는 전용 키가 없으면 관광 키로 대신 시도한다. 다만 **공백뿐인 값이나 `off`는 "끈다"는 뜻**이고
  빈 값과 다르다. 이 구분을 없애면 외부 호출을 막을 방법이 사라진다.
- 좌표 변환은 알려진 지점으로 검증할 수 있게 순수 함수로 둔다.

## 테스트

- 좌표 변환은 알려진 지점 **3곳 이상**에서 오차 10m 이내인지 단언한다.
- 이동 추정은 짧은 거리에서 도보로 바뀌는 경계와, 도심에서 세 자리 분이 나오지 않는다는 것을 확인한다.
- 기상 키 해석은 네 경우(없음 / 빈 값 / 공백뿐 / 실제 값)를 각각 고정한다.
- 외부 호출은 전부 가짜 응답으로 대체한다.
