# 일정 엔진 (`src/engine/`)

## 맡는 것

이 제품의 **유일한 판정 경로**다. 하루 입력으로 하루 일정을 만들고, 체류 전체를 조립하고, 변화가
생기면 다시 판정한다.

- 후보 안전 게이트와 복귀 계산 — 예전 단일 외출 흐름에서 쓰던 것을 그대로 이어 쓴다
- 하루 일정 생성: 고정 블록과 마감으로 외출 창을 나누고, 식사 칸을 기준으로 외출을 만들고,
  정거장을 고르고, 복귀 계산식·보행 누적·이동 한도를 만족할 때까지 줄인다
- 체류 전체 조립: 날짜 순회, 체류 중 같은 장소 1회 규칙, 데모 사건 적용, 즉시 복귀
- 재계획: 확정 일정을 게이트 1단계부터 다시 판정해 **최소 변경**으로 고친다
- 교체 후보(최대 5개)와 전후 비교

## 맡지 않는 것

- 조건 합성·날짜 분류·기본값 — `src/stay/`의 결과를 **그대로 쓴다.** 여기서 다시 계산하지 않는다
- 외부 호출 — 후보·이동시간·기상은 모두 인자로 받는다
- 저장·요청 조립·화면 — `lib/`, `app/`, `components/`
- 문구와 번역. 엔진은 사유 코드만 내보내고 문장은 만들지 않는다

## 항상 지켜야 하는 것

- **결정적이다.** 같은 입력이면 같은 결과가 나온다. 시계와 난수를 읽지 않고 현재 시각은 입력이다.
  후보를 다룰 때는 항상 같은 순서(장소 id 순)로 다룬다.
- **판정은 언어와 무관하다.** 표시 언어 제목·주소는 정거장의 표시 필드에만 들어가고 게이트·순위에
  영향을 주지 않는다. 언어만 바꿨을 때 정거장 목록과 상태가 달라지면 결함이다.
- 후보 게이트는 하나의 게이트 함수, 복귀 계산은 하나의 계산 함수만 쓴다. **같은 판정을 하는 두 번째
  경로를 만들지 않는다.**
- 복귀 계산식을 만족하지 못하면 외출을 만들지 않는다. 체류를 줄여 맞출 수 있지만 정거장당 15분
  미만으로는 줄이지 않는다.
- 보행 한도는 **외출 1회 누적**, 이동 한도는 **구간당**이다. 둘을 바꿔 적용하지 않는다.
- 의료 시설은 정거장이 되지 않는다. 판정 입력은 **분류 코드와 한국어 원문 이름**이다 — 한국어
  원문이 없으면 분류 코드만 보고, 표시 언어 이름으로 떨어지지 않는다. 떨어지면 단서 목록이
  한국어·영어 위주라 일본어·중국어 사용자에게만 걸러지지 않는 장소가 생긴다.
- 열려 있다고 단정하지 않는다.
- **복귀 병원은 찾아서 쓴다.** 복귀 장소가 병원이면 그 복귀가 가리키는 병원 id로 찾는다.
  **다른 병원을 대신 고르지 않는다** — 병원이 여러 곳인 체류는 정상이고(직접 등록한 곳,
  연동으로 더해진 곳), 이 계산은 즉시 복귀처럼 숫자가 가장 중요한 순간에 돈다.
  못 찾았을 때는 호출 지점에 따라 다르다: 잘라낸 외출을 다시 계산할 때는 계산을 포기하고 기존 값을
  두고, 재계획에서 복귀 지점을 잡을 때는 숙소 좌표로 떨어진다(복귀 지점이 없으면 그날을 만들 수 없다).
- 재계획은 지난 날짜와, 오늘 중 이미 시작된 정거장·출발한 외출을 건드리지 않는다.
- 고정한 장소는 게이트를 통과하면 유지하고, 지운 장소는 자동 채움에 다시 넣지 않고, 비운 식사 칸은
  다시 채우지 않는다.
- **변화가 필요한데 전후 비교가 비어 있으면 실패다.** 알림만 하고 일정을 그대로 두지 않는다.
- 정거장 id는 `날짜:역할:장소id`로 결정된다. 무작위 id를 만들지 않는다.
- 경고와 표시 라벨의 순서 정본은 한 파일(`displayOrder.js`)이다. 한쪽 모듈에만 값을 더하면
  재계획·언어 변경을 거친 날짜에서 그 값이 조용히 사라진다.
- 모든 외출에서 예상 귀가 시각 ≤ 안전 마감이 성립한다.

## 구현 방식

- 하루 만들기와 하루 고치기를 나눈다. 확정 일정이 있으면 **고치는 쪽**으로 가고, 없거나 다시 만들기면
  새로 만드는 쪽으로 간다. 고치는 쪽은 통과하지 못한 정거장만 대체 → 체류 축소 → 제외 →
  외출 취소 순으로 처리한다.
- 마감은 후보 여러 개 중 가장 이른 것을 고르고, **어느 후보가 마감을 만들었는지 이유를 함께** 남긴다.
  이유가 없으면 화면이 "왜 이 시각까지인지"를 설명할 수 없다.
- 병원 일정 직전 마지막 외출만 그 병원에서 끝난다. 그 경우 병원 일정 블록은 일정 시작 시각부터
  시작한다 — 숙소→병원 이동을 블록에도 넣으면 외출의 마지막 구간과 이중 계산된다.
- 합친 하루도 외출당·하루 정거장 한도를 지킨다(식사 정거장 포함).

## 테스트

- 결정성: 같은 입력을 두 번 넣어 결과가 같은지 단언한다.
- 언어 무관성: 네 언어로 같은 입력을 넣어 날짜별 상태와 정거장 장소 id 목록이 같은지 단언한다.
- 마감 이유는 다섯 종류를 각각 만드는 입력으로 확인한다.
- 재계획은 고정·삭제·지난 날짜·전후 비교 네 가지를 각각 고정한다.
- 식사 칸은 통과한 식당이 없을 때 '추천 장소 없음'이 되고 **다른 정거장으로 채우지 않는다**는 것을
  단언한다.
- 보호자 외출은 환자가 숙소에 있는 구간 안에만 있고 환자 병원 일정과 겹치지 않는지 확인한다.
