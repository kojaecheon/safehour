# 체류·조건 도메인 (`src/stay/`)

## 맡는 것

체류와 조건 기간에 관한 **순수 규칙**이다. 여기서 나오는 값이 일정 엔진·서버·화면의 공통 입력이 된다.

- 체류 저장 검증(날짜 역순, 45박 초과, 수술·시술 일정 필수, 숙소 날짜 겹침)
- 날짜 D의 숙소 고르기(체크인 ≤ D < 체크아웃, 출국일만 전날 밤 숙소), 하루 활동 창 계산,
  입국일 시작·출국일 마감
- 병원 일정 블록 계산
- 조건 기간 검증과 **날짜별 합성** — '모르겠음'을 기본값으로 바꾸고 항목별로 가장 엄격한 값을 고르며
  값마다 출처를 남긴다
- 날짜 분류(자유일 / 제한 없음 선언일 / 제한일 / 휴식일 / 입력 필요)와 그 사유
- 오늘 게이트 덧씌우기 — 저장된 일정을 바꾸지 않고 표시 시점에 상태를 낮추는 순수 함수
- 시각·날짜 계산(한국 표준시 고정)
- **조정 가능한 숫자 기본값의 정본**(`defaults.js`)

`src/domain/states.js`(날짜 상태와 사유 코드의 닫힌 집합)도 이 계층이 함께 소유한다. 사유 코드를
더하는 건 여기서만 하고, 그 문구는 문구 사전이 채운다.

## 맡지 않는 것

- 장소 후보를 고르거나 외출을 조립하는 일 — `src/engine/`
- 외부 호출(관광공사·기상·주소) — `src/tour-api/`, `src/adapters/`
- 저장·화면·요청 조립 — `lib/`, `app/`, `components/`
- 단서 목록(열·물·매운·날음식·주점·카페, 관심사 매핑). 이 값들은 관광 후보 모듈이 갖는다.
  숫자만 여기 있고 목록은 여기 없다

## 항상 지켜야 하는 것

- **브라우저 API도 네트워크도 쓰지 않는다.** `window`·`fetch`·파일 접근이 들어오면 이 계층을
  단위 테스트에서 그대로 불러올 수 없게 된다.
- 순수 함수다. 입력 객체를 고치지 않고, 시계와 난수를 읽지 않는다. 현재 시각은 인자로 받는다.
- 모든 시각은 한국 표준시다. 오프셋 없는 시각 문자열을 표준 파싱에 바로 넘기지 않는다 —
  이 폴더의 시각 파싱 함수를 쓴다. 안 그러면 다른 시간대 환경에서 결과가 달라진다.
- 합성 결과의 모든 값에는 출처(기간 id, 출처 종류, 기본값 여부)가 붙는다. 출처 없는 값을 만들지 않는다.
- 필수 항목(외출 허용, 복귀 시각)에는 '모르겠음'이 없다. 병원 발행 기간에도 '모르겠음'이 없다.
- 예/아니오 항목은 **'예 = 제한'** 방향으로만 만든다. 반대 방향 항목을 하나라도 만들면 '모르겠음'을
  엄격한 쪽으로 채우는 규칙이 그 항목에서만 뒤집힌다.
- 기본값 파일은 이 폴더가 **쓰고**, 다른 모듈은 읽기만 한다. '사람 검토 전 임시값' 주석이 붙은 값을
  더 느슨하게 바꾸지 않는다.
- 사유 코드는 닫힌 집합이다. 새 사유가 필요하면 추가하기 전에 보고한다.

## 구현 방식

- 공개 진입점은 `index.js` 하나다. 다른 모듈은 개별 파일을 직접 가져가지 말고 진입점을 쓴다.
- 기본값 객체는 깊은 동결 상태로 내보낸다. 읽는 쪽이 실수로 고칠 수 없게 한다.
- 검증 함수는 예외를 던지지 않고 **문제 목록을 담은 결과 객체**를 돌려준다. 화면이 항목별로 오류를
  보여줘야 하기 때문이다.
- 합성은 기간 전체를 고르지 않고 **항목마다** 가장 엄격한 값을 고른다. 한 병원 기간 안의 모순
  (동행 필요 = 예 + 곁 지키기 = 아니오)만 그 기간이 덮는 날짜를 통째로 막는다.

## 테스트

- 합성은 기간이 겹치는 조합으로 항목마다 확인한다: 보행 한도는 작은 값, 복귀 시각은 이른 값,
  외출 허용은 금지가 이김, 출처가 기록됨.
- 날짜 분류는 수술 후 경계일 **앞뒤**를 각각 확인한다. 경계일 전 빈 날짜는 자유일, 경계일 이후 빈
  날짜는 입력 필요다. 이 둘을 섞으면 수술 뒤 날짜가 제한 없이 열린다.
- 병원 기간의 유효기간이 그날 활동 종료 시각보다 이른 경우, 그 지침은 그날을 덮지 않는다.
- 오늘 게이트 덧씌우기는 **입력 일정을 바꾸지 않는다**는 것을 함께 단언한다.
- 시간대 의존을 잡으려면 `TZ=America/New_York`으로도 한 번 돌린다.
